### Getting started

**Prerequisites:** [Node.js](https://nodejs.org/) and Git.

```sh
git clone https://github.com/ZuhaibShahid/Haris-Portfolio.git
cd Haris-Portfolio
npm install
npm run dev
```

Open the local URL printed by Vite.
